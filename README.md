# ZeD Lab Meetings

Repository for weekly ZeD Lab meeting materials.

Meetings are held **Wednesdays, 3:00–5:00 PM**, through December 16, 2026.

## Pre-meeting requirement

Each lab member must place a **one-page update** in the `slides/` folder for the relevant meeting date **before the meeting**.

Zoom: https://uky.zoom.us/my/zedlab

Meeting folders use the `YYYY-MM-DD` naming convention.
